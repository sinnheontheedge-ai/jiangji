# 第1层：真实执行链唯一性 - ❌ 失败

## 审计结论
❌ **执行链完全断裂，系统无法运行**

## P0阻塞清单

### P0-1: 信号→执行断链
**文件**: `strategy_manager.py:153`
**问题**: 发布signal:trade事件，但无任何模块订阅
**影响**: 信号生成后无人处理，交易永远不会执行
**证据**:
```bash
grep -r "signal:trade" backend/
# 结果：只有strategy_manager.py发布，无任何订阅
```

### P0-2: 执行→下单断链
**文件**: `trade_executor.py:421`
**问题**: _execute_trade方法定义，但永远不被调用
**影响**: 下单逻辑永远不会执行
**证据**:
```bash
grep -r "_execute_trade" backend/
# 结果：只在trade_executor.py中定义，无任何调用
```

### P0-3: 下单→EventBus断链
**文件**: `trade_executor.py`
**问题**: trade_executor不发布任何事件
**影响**: 下单成功/失败无法通知其他模块
**证据**:
```bash
grep -r "event_bus.publish" core/trade_executor.py
# 结果：无匹配
```

### P0-4: EventBus→WebSocket断链
**文件**: `websocket_manager.py:28-31`
**问题**: 订阅order.created/order.filled/position.updated，但无人发布
**影响**: WebSocket永远不会推送
**证据**: trade_executor不发布这些事件

### P0-5: 存在旁路路径
**文件**: `main.py:20`, `api/positions.py:160`, `plugins/execution_engine/order_executor.py:389`
**问题**: 插件直接导入，API直接调用binance_client，绕过trade_executor
**影响**: 执行链不唯一，无法统一控制

# 第2层：仓位安全 - ❌ 失败

## 审计结论
❌ **存在多个仓位翻倍风险路径**

## P0阻塞清单

### P0-6: 无统一下单入口
**文件**: `api/positions.py:160`, `trade_executor.py:369`, `risk_monitor.py:349`, `plugins/execution_engine/order_executor.py:389`
**问题**: 4个下单入口，无法统一控制
**影响**: 无法统一审计，无法统一安全检查

### P0-7: clientOrderId无业务含义
**文件**: `binance_client.py:209-212`
**问题**: 自动生成UUID，无业务含义
**影响**: 无法通过clientOrderId追踪订单来源，无法防止业务层重复下单

### P0-8: 网络重试会重复下单
**文件**: `binance_client.py:209-212`
**问题**: 每次调用生成新UUID
**影响**: 网络超时重试会生成新UUID，导致重复下单

### P0-9: DB写入失败无补偿
**文件**: `trade_executor.py:369-529`
**问题**: 先下单，再DB写入，commit失败无补偿
**影响**: 订单已提交但DB无记录，订单泄漏

### P0-10: 止盈止损未设置reduceOnly
**文件**: `trade_executor.py:417, 428`
**问题**: 止盈止损订单未设置reduceOnly
**影响**: 持仓已平后，止盈止损触发会开新仓

### P0-11: 调用不存在的函数
**文件**: `trade_executor.py:428`, `risk_monitor.py:349, 433`
**问题**: 调用create_stop_market_order，但函数不存在
**影响**: 系统崩溃

### P0-12: 单仓模式检查不生效
**文件**: `trade_executor.py:439-454`
**问题**: 单仓模式检查存在，但_execute_trade永远不被调用
**影响**: 单仓模式检查永远不生效，可能开多个仓位

# 第5层：EventBus - ❌ 失败（已审计）

## 审计结论
❌ **EventBus断链，Redis断开后永久失效**

## P0阻塞清单

### P0-13: trade_executor未发布事件
**文件**: `trade_executor.py`
**问题**: 无任何event_bus.publish调用
**影响**: 下单成功/失败、持仓创建/更新无事件，EventBus断链

### P0-14: trade_executor未订阅signal:trade
**文件**: `trade_executor.py`
**问题**: 无任何订阅代码
**影响**: 信号生成后无人处理，交易信号断链

### P0-15: order.created事件无发布者
**文件**: 全局搜索
**问题**: websocket_manager订阅了order.created，但无人发布
**影响**: 订阅了一个永远不会触发的事件

### P0-16: Redis断开后无重连机制
**文件**: `event_bus.py:94-129`
**问题**: Redis连接断开后，redis_client和pubsub未重新创建
**影响**: Redis断开后EventBus永久失效

### P0-17: publish在commit之前
**文件**: `websocket_event_bridge.py`, `fund_monitor.py`
**问题**: publish后commit失败，事件已发布但数据库未提交
**影响**: 状态不一致
